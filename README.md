# Hospital-Management-System-Testing
Manual testing project for Hospital Management System

## Project Overview

This project contains manual testing activities performed on a
Hospital Management System.

## Role

Manual QA Tester

## Modules Tested

- Login
- Patient Dashboard
- Receptionist
- Nurse
- Doctor
- Lab Technician
- Pharmacy
- Billing
- Admin
- Reports

## Testing Types

- Functional Testing
- Smoke Testing
- Regression Testing
- Retesting
- UI Testing
- Positive Testing
- Negative Testing
- Validation Testing

## Test Artifacts

- Test Scenarios
- Test Cases
- Test Execution Results
- Bug Reports
- Screenshots

## Tools Used

- Microsoft Excel
- Postman
- Chrome DevTools
- MobSF
- ADB

## Test Case Details

The Excel file contains test scenarios, test cases, test steps,
test data, expected results, actual results, status, severity,
priority and retesting details.

## Project Outcome

Identified functional, validation and UI-related defects during
manual testing and documented them with appropriate severity and
priority.
